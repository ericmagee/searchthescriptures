## The proposals

None of these is built. Each is a change to the engine and needs the operator's instruction.

1. **A close-round guard fence at the oracle seat.** Before an oracle close is accepted, scan it for the forbidden forms the topic's guards name and refuse or flag the round by guard number. Computable from stored text with no model call, the same shape as the fold verdict lint. The plain seat is not scanned, because it stands under no guard.
2. **An out-of-round text rule, both seats.** Any sentence after the last graded line of a close is either absent or counted as a concession against that side's own links. This one is mechanical and names no doctrine, so it can apply to the plain seat without serving it anything. Today it is invisible to the audit by design.
3. **A keystone rule for a guarded topic, at the oracle seat.** Where a guard states the load order, the oracle's chain carries the guard's ground as its keystone and the inference as a footed layer, checked before the run fires.
4. **Verdict columns never empty.** When the extractor refuses a row, it writes the judge's own top line with a quarantine reason rather than leaving the columns null.
5. **Read the served set against the losses, rather than reversing the seats.** The seats cannot be reversed: the plain seat would have to be served the sights, conclusions and guards, which destroys the only thing it is for. The measurement that can be made instead is to read whole the oracle rounds of the runs marked strained, and ask of each what the served set gave the seat to stand on and what it did not. That is a read, not an engine change, and it is the one this review did not make.
6. **Guard restatement at the close of the oracle prompt.** Put the guard's forbidden list at the end of the oracle's close-round prompt, since the served guard block truncates and front-loading is the documented remedy. The plain prompt is untouched.
7. **One judge is not a panel.** Either record the panel or say single judge in the columns, so that no row claims a verdict no panel gave.
