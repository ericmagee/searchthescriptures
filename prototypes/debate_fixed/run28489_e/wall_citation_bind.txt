THE REPORT (relayed by the operator, in substance): when a quotation sits after one reference but its true reference follows it, the citation checker binds the quote to the reference before it, reports a mismatch, then self-heals to the reference beside it; the 2026-10-27 run listed 6 such "near-reference" rows, parse artifacts and not bad citations. Example from that run: "'Joseph her husband' (Matthew 1:19), 'Mary thy wife' (1:20)", where "Mary thy wife" was first bound to Matthew 1:19 and only then matched to 1:20. The list is operator-facing; artifacts teach distrust; if the self-heal misses, a correct citation is counted as not matching. Fix shape: bind each quote to the candidate references on both sides before declaring a mismatch, prefer the reference after the quote in the "'quote' (ref)" pattern, list a near-reference row only when no adjacent candidate matches; one change in the citation nodes.

PRIOR ART: the fallback is operator ruling 4 of 2026-10-13 (WALL-0966 replies 1215, 1262, 1264): "try the nearer reference only when the first fails", and the document lists each such match. The design binds first to the earlier reference by intent; the artifacts are its foreseeable cost and were not raised as a defect then. THE CODE, LIVE (read 2026-10-28 from ORACLE_DEBATE_V1 active version 23cf8db4), not carried: Citation Scan's main pattern pairs a reference with the quotation after it (up to 30 characters between) and keeps a second reference between them, or a bracketed reference right after the quote, as "alt". A quote-first pairing ("quote" (ref)) is skipped when the reference-first pattern has already taken that quote, unless a line break or sentence end lies between. Quote Compare scores the quote against the first verse (at least 75% of its words of 3+ letters) and tries "alt" only when that fails, marking rebound_from. Format Markdown lists every rebound match as "made on a nearer reference ... after the first reference before it did not match". The judges' KJV block lists only non-matching items, so rebound rows never reach a judge (WALL-0966 1262, 1264).
