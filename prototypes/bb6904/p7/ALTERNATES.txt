1. WHEN AN ALTERNATE IS CALLED
- A panel seat is not counted under option 2 (6965; 5B): drv_uncured > 0 after the cure path, that is, at least one K-B, K-G1 or
  K-G3 item of that seat not CURED. Nothing else calls an alternate: an unreadable or truncated seat keeps today's reserve path
  (Panel Check, Reserve Build, odv1_record_panel_substitution), which is separate and unchanged.
- One alternate per removed seat per debate (6904 g). The pool holds two models and G3 makes one debate's alternates distinct, so
  at most two alternates sit in a debate; a third removed seat stays not counted (AMEND 1, 6980).
- The single judge is outside the panel and sets no outcome; it gets no alternate.

3. WHAT THE ALTERNATE READS (a fresh read, without the removed ruling)
- The same rulebook and transcript the removed seat was given: its own request's system and user text, read exactly as Reserve
  Build reads a failed slot's call today (b0.systemInstruction or b0.messages[0..1]). Not the removed seat's answer, not its
  report lines, not its cure exchange, not the other seats' rulings.
- The body follows the OpenRouter family shape Reserve Build uses (model, max_tokens, reasoning effort, messages). Effort is fixed
  at the maximum for both pool models (operator, 6978): reasoning {effort:'max'}, written into each seat's configuration, never
  left to a provider default. Qualification (section 7) runs at the same setting; if max spends the whole token cap before
  answering, as glm's did (BB-5693 rev 6), that is reported to the operator, not changed by us.

4. HOW IT IS ACCEPTED (mechanical)
- The alternate's answer goes through the same code as a panel seat: Panel Payloads' verdict reader and closed-set checks, then
  drvCheck (K-B, K-G1, K-G3), then the same cure path with its one cure call in the fixed form (6952). It is counted only if it is
  clean and its drv_uncured is 0, exactly as any seat (5B). A failed call, an unreadable answer or an uncured item leaves the
  seat not counted. No second alternate.

5. THE REMOVED RULING IS KEPT AND MARKED
- debate_judgments holds one row per seat in panel_expected; derive_debate_outcome refuses an undispatched seat (FENCE 4). So the
  removed ruling cannot stay there beside its alternate. Proposed: a new debate_results column drv_removed jsonb, an array of
  {seat, api_model, verdict_tag, standings, drv_uncured, verdict_raw with its report lines, replaced_by, at}, written once before
  any judgment row, with panel_expected rewritten to name the alternate seat (as odv1_record_panel_substitution does today for a
  reserve: before any judgment row, one call, every refusal raises). A new function, not that one: that one allows one
  substitution per run and only the seven named engines.
- The markdown (step 6's section) gains one line per removed seat: "<seat> was not counted (uncured: ...); <alternate> sat".
- The alternate's row carries its own drv_uncured and report lines like any seat.

6. REPEAT REMOVALS ARE REPORTED
- A read-only query (or view) over drv_removed: removals per api_model over its last N panel seats, with the rules that removed it.
  Reported in each run's markdown for the seats on that panel, and on demand. No automatic action: what a repeat count triggers
  (benching a model, a review) is the operator's choice.

7. QUALIFICATION BEFORE ANY LIVE USE (6975)
- Each pool model is run as a dry regrade judge on 27191, 27088 and 27259 (replay rows only; record_replay_judgments; no outcome
  written). Measured per run: finished within the 900 s timeout; finish_reason; verdict and standings in the closed sets;
  K-B, K-G1, K-G3 items; the cure call's result; seconds and tokens.
- MECHANISM (AMEND 2, 6980): today a dry regrade seats only the panel's three, so no path seats a pool model. Proposed: a dry-only
  request field, qualify_alternate: <pool seat>, read by Init Seats and refused unless dry is true. It forces the alternate path
  for every panel seat of that dry run, whatever its drv_uncured, with the named pool model; Replay Rows records the alternates'
  rows in the removed seats' places. The qualification therefore runs the same Alternate nodes a live run would.
- Proposed bar, for the advisor to rule: 3 of 3 readable, within the timeout, and finish_reason not "length". Violation and cure rates are reported, not
  gated, since they are what alternates exist to absorb.

8. WHERE IT WOULD SIT IN THE FLOW (for the later build; not now)
- After Panel Cure Check and before Dry?: Alternate Needed? (any seat drv_uncured > 0 and a pool model passes the guards) ->
  Alternate Build -> Alternate Route -> Alternate Call (OpenRouter) -> Alternate Payloads (the panel reader and drvCheck) ->
  the cure path again for the alternates (AMEND 4, 6980: Alternate Cure Build, a copy of Panel Cure Build that takes each
  alternate's own request body and model from Alternate Build, not from Panel Build's judges; the rest of the cure nodes are
  shared code) -> Alternate Merge (bodies and summary with the alternate in the removed seat's place;
  the removed ruling into drv_removed). The named reads of Panel Cure Check (Write Judgment 1-3, Derive Outcome, Panel Done,
  Replay Rows, Record Substitution) move to Alternate Merge, as portion 4 moved them.
- Live path (AMEND 3, 6980): two writes, in this order, both before Write Judgment 1: Record Substitution (the reserve, today's
  function, unchanged), then Record Alternates (the new function). The new function writes drv_removed and rewrites panel_expected
  only; it never writes panel_substitution, so a debate may hold one reserve substitution and up to two alternates. It refuses
  if any judgment row exists, if an alternate is a seated debater (G1), the replaced seat's model (G2) or already in
  panel_expected (G3), and it reads panel_expected as the reserve write left it. Dry path: Replay Rows records the
  alternate as the seat's replay row; drv_removed is not written on a dry run.

  Tokens: about the size of one panel seat each.
