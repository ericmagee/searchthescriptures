## pkgUOW: "what the record leaves open" reads a longer phrase

Where: Shared Library, UND.OPEN (the pattern undOk uses). undOk is called by the pkgUND send-back cure (MISSING COLLISION GRADE), by the E-HOLD send-back cure on an UNDERDETERMINED line, and by pkgUNA (UNDERDETERMINED WITHOUT ITS GROUNDS) on every UNDERDETERMINED collision line of an alternate's verdict.

What changed: an UNDERDETERMINED line states what the record leaves open when it says "leave" or "leaves", then up to 8 words, then open, disputed, undecided, unsettled, unresolved, contested or in dispute. Before this package the limit was 3 words, each of letters, digits or underscore only, so a possessive with a curly apostrophe ("Joseph’s") or a longer phrase failed. A word here is any run of characters without a space, period, semicolon, colon or comma, so the phrase cannot run across a clause or a sentence. Every other form the pattern accepted is unchanged.

Why: run 35173, luna's send-back item S11. The line "D4 vs C6 (Luke 3:23): UNDERDETERMINED -- ... leave the biological status of Joseph’s fatherhood open -- GROUND: [L1] Luke 3:23 ..." was counted uncured with only the fault "the line does not state what the record leaves open".

Size: +7 characters of code (measured), prompt 0.

Limits: the pattern stays a word list. It still misses "disputing", "differ on" and similar forms. A negated phrase such as "leaves nothing open" was already accepted before this package and still is.
